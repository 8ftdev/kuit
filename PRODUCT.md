# Kuit

A personal component library populated from local projects by a Go CLI. Bun handles dependency resolution and all JavaScript tooling. The user imports React, Vue, Svelte or Solid source into an Astro viewer. Success is a working isolated preview with readable copied source and a read-only Props table.

Keep the UI to a navbar and Preview / Code / Props. No sidebar, TOC, promotional content or floating secondary demo panel. Source files have copy support and a bounded scrolling viewport.
