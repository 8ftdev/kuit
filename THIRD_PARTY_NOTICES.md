# UI sources

- Expandable menu navbar: [Ruixen UI](https://ruixen.com/docs/sections/expandable-menu-navbar), retrieved from `https://ruixen.com/r/expandable-menu-navbar.json`. Adapted for library navigation and keyboard use.
- Magnetic tabs: [Ruixen UI registry](https://ruixen.com/r/baseui/magnetic-tabs), installed through the shadcn CLI with Bun. Adapted with ARIA tab semantics, keyboard navigation and reduced-motion support.
- `site/src/components/react/code-block.tsx` and `real-code-block.tsx`: provided locally by the user from their Tailark component access. The renderer identifies [Origin UI](https://github.com/origin-space/originui/blob/main/components/code-block.tsx) as its source. These supplied sources retain their upstream terms; no broader redistribution license is granted here.
- Fumadocs, Astro, Shiki, Motion and other package licenses are included with their installed packages.

- Icon breadcrumbs: [Ruixen UI registry](https://ruixen.com/r/baseui/breadcrumb-icon), installed through the shadcn CLI with Bun.
